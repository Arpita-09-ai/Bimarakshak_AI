AI-Driven Motor Insurance Risk Assessment System

Project Introduction

BimaRakshak AI is a database-driven system that uses AI and IoT data to assess real-time driving behavior for fairer motor insurance premium calculations. The project demonstrates core Database Engineering concepts such as ER modeling, normalization, and SQL-based data management.

Database Schema

Table Primary Key Foreign Keys Description
Drivers DriverID - Stores driver details
Vehicles VehicleID DriverID Stores vehicle info linked to driver
Trips TripID DriverID, VehicleID Records trip data (distance, speed, etc.)
RiskScores ScoreID TripID Stores AI-generated risk metrics

Reports Generated

  • Driver Risk Scores: Aggregates risk per driver from trips.
  • Accident-Prone Zones: Identifies areas with frequent risky behavior.
  • Driver Feedback: Suggests safer driving practices based on data.
